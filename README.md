# hxwl-03 压水试验复核台

在原岩土钻孔编录面板上扩展出的压水试验（压水/注水 Lugeon）现场复核台。
解决纸上抄录与连续分层错位、三级流量稳定性汇总时才发现、以及成果改值无留痕的问题。

## 技术栈

React + Vite + TypeScript + CSS（无额外依赖，localStorage 本机保存）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5103

## 工作流

1. **选孔 + 选试段**：左侧钻孔列表按孔号进入；顶部按连续分层比例显示分层条，
   登记试段顶/底深后实时反查命中分层（落在同一层 / 跨层即时提示）。
2. **登记资料**：试验设定压力、管路损失、三级压力与流量、各级时长、日期与记录人；
   录入时即时显示扣除管路损失后的有效压力、压力偏离百分比、后两级流量差。
3. **自动判定**：提交时由纯规则引擎判定——
   - 试段跨越一个以上已编录分层 → 待复核（跨层）
   - 任一级有效压力偏离设定值超过 10% → 待复核（压力偏离一成）
   - 第三级与第二级流量差 >10% → 待复核（后两级流量未稳定）
   - 资料未填齐 → 提示补齐，不进入确认
4. **待复核闭环**：硬性问题自动写入原因，可补充说明；支持“资料更正后重新判定”
   或直接“登记复测”（预填原试段资料，新记录通过后自动替代原记录）。
5. **负责人确认**：判定合格的试段由负责人填入渗透系数 K（m/d 或 cm/s）并签名，
   确认瞬间把资料快照与结果一起冻结；参考吕荣值 Lu=Q/(P有效·L) 同步显示。
6. **改值留版本**：冻结后只能“事后改值”，必须填写改值原因，生成新版本；
   原冻结版本永久保留在版本历史中。

## 分层存储（重开可按孔号接续）

| 命名空间 | 内容 |
| --- | --- |
| `pwt:data:v1` | 资料：钻孔连续分层 + 试验登记 |
| `pwt:verdicts:v1` | 判定：状态、待复核原因、确认人、冻结版本 |
| `pwt:ui:v1` | 本机：上次查看的孔号、标签页 |

判定逻辑（`src/rules.ts`）是纯函数，不接触存储；存储层（`src/storage.ts`）负责读写。
关闭重开后自动回到上次的孔号，待复核、已确认记录均在。
