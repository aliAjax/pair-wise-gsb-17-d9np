# hxwl-03 压水试验复核台

在原"岩土钻孔编录"面板上扩展而成：现场把压力、流量抄录回本机后，逐孔逐段完成
**试段选取 → 读数登记 → 规则判定 → 原因/复测 → 负责人确认冻结 → 修订留版本** 的完整复核闭环。

## 技术栈

React + Vite + TypeScript + CSS，无后端，数据全部保存在本机 IndexedDB。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5103

## 工作流

1. **选取试段**：在连续分层条上只能用分层分界作顶界/底界，杜绝试段与编录分层错位；
   选段即提示是否跨层。
2. **登记资料**：每段登记试验压力（设定/实测表压）、三级稳定流量、各级时长、管路损失；
   初测、复测、修订补测只追加，不改写原读数。
3. **自动判定（阈值一成）**：
   - 试段跨层；
   - 任一级实测压力偏离设定值 > 10%；
   - 后两级折算透水率 q=Q/(P·L) 差异 > 10%（原始流量随压力变化，不可直接比较）。
   命中任一即留 **待复核**，须逐项写明原因并复测；最新复测压力/流量仍不稳则不能放行。
4. **确认冻结**：放行后进入待确认，系统给出透水率（Lugeon，q=Q/(P·L)）与渗透系数
   建议值（Hvorslev 栓塞段解析解，有效压力 = 表压 − 管路损失 + 中点水柱压力）；
   负责人可调整 k，签名确认后**立即冻结只读**。
5. **事后改值**：必须填写改值原因并做修订补测，重新确认后另存新版本，
   v1/v2… 版本链与原因全部保留备查。
6. **按孔接续**：左栏孔号显示各孔待复核/已确认计数，当前孔号记在本机设置库，
   重开页面自动回到上次的孔继续处理。

## 存储分层（三个独立 IndexedDB 数据库）

| 库 | 内容 |
| --- | --- |
| `wpt_raw_material`（资料库） | 钻孔分层、试段、各测次原始读数（只追加） |
| `wpt_verdict`（判定库） | 待复核原因、状态、冻结版本（与资料物理分开） |
| `wpt_local_settings`（本机设置库） | 上次查看的孔号 |

资料导出与判定导出分别生成 JSON。首次打开时写入三个孔的示例数据
（含待复核、待确认、已确认并修订出 v2 三种状态）；清空对应数据库后重开可重新获得示例。
